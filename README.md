# ☕ Back-end - Sistema de Cadastro de Clientes
![Java](https://img.shields.io/badge/java-%23ED8B00.svg?style=flat&logo=java&logoColor=white)
![Maven](https://img.shields.io/badge/apache_maven-C71A36?style=flat&logo=apachemaven&logoColor=white)
Este repositório contém um sistema de back-end desenvolvido em Java utilizando Maven. O projeto foca no desenvolvimento de um sistema robusto de cadastro de clientes.
## 📁 Estrutura de Pastas
- cadastrocliente/: Lógica principal.
- aula29_02/: Exercícios práticos.
## 🛠️ Tecnologias
- Java, Maven, HTML.
## ⚙️ Execução
1. JDK e Maven instalados. 2. mvn clean install. 3. mvn exec:java.
